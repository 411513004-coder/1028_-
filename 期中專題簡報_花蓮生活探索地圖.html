Problem Statement & Target Audience · 打造一站式花蓮綠色生活指南

🚨 現有痛點 (Pain Points)

  • 蔬食飲食分類混雜：主流地圖將「純素」、「蛋奶素」與「葷素共食」混淆，素食者需反覆致電確認。
  • 資訊零散割裂：傳統美食地圖缺乏必訪文化景點與休憩咖啡廳的橫向串連。
  • 幽靈店家困擾：網路舊名單常充斥已停業或轉型店家，容易撲空。
  • 資安與維護門檻：商業地圖 API 申請繁瑣、計費昂貴且有金鑰洩漏風險。

👥 目標受眾 (Target Audience)

  • 花蓮在地居民與蔬食族群：快速掌握花蓮市、吉安等區域安心用餐新選擇。
  • 大專院校師生：東華大學志學商圈、慈濟建國校區周邊平價美食與自習咖啡空間。
  • 自由行深度旅遊觀光客：跨越新城、壽豐、秀林與鳳林，無縫串聯山海自然與人文名店。
  • 重視永續低碳的生活推廣者：鼓勵大眾實踐減碳飲食與在地慢活步調。

🚀 技術亮點、測試成果與下一步

Technical Highlights, Testing & Next Steps · 扎實落地與持續演進

⚙️ 技術亮點與測試成果

  • 100% 零商業金鑰：採用 Esri 街道圖與高解析衛星空照圖，無 API 費用、無額度上限、杜絕資安外洩。
  • 極致輕量與零依賴：首頁載入小於 0.3 秒，免安裝 Python 或 Node.js，任何設備雙擊 `index.html` 即可運行。
  • 雙向連動架構：左側卡片與地圖 Pin 雙向聚焦（FlyTo 動態位移、平滑滾動）。
  • 全平臺適配：支援電腦寬螢幕雙欄與手機端自適應抽屜介面；已部署 GitHub Pages 免費線上即時體驗。

🔮 未來發展規劃 (Next Steps)

  • 自由行多點行程自動規劃：支援使用者一鍵將想去的地點加入清單，演算法自動串聯最佳路線。
  • GPS 即時定位與距離排序：整合 HTML5 Geolocation API，自動計算距離當前位置最近的據點。
  • PWA 離線快取技術：引入 Service Worker，將地圖底圖快取至手機端，即便行經太魯閣山區或蘇花公路亦可離線查閱。
  • 小農與在地店家線上回報：打造社群協同投稿機制，促進花蓮在地綠色經濟共好循環。
